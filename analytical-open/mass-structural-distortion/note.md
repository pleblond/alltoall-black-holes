# Mass gap from coordination, with an explicit lower bound

The field energy of a normalized eigenmode is its eigenvalue. The vacuum
reference on J2 is the band edge \(-8\) (VPLUS is \(-8\) on the finite
torus as well, for the uniform mode of the \(8\)-regular graph). Define

\[
m=-8-E_0
\]

when \(E_0<-8\), and \(m=0\) when the spectrum does not go below the edge.

`matter-stable-composite/note.md` gives \(m\ge n-9\) for an embedded
\(K_n\), \(n\ge 10\). That is a lower bound in hopping units, with \(J=1\),
and it is produced entirely by extra edges inside the support of the trial
vector. No continuum mass parameter enters.

Under-coordination cannot use this trial vector. Removing edges lowers the
Rayleigh quotient of the all-ones vector toward the interior of the band.
The spectral-mass mechanism for a **stable** gap is excess coordination,
which is the tension side of P0'. A rarefied defect is a scattering site,
not a bound state below the edge, unless some other trial vector says
otherwise. The default expectation to test is: tense motifs bind, floppy
motifs radiate.

Because \(E_\psi=\langle\psi|H|\psi\rangle\) for a normalized state is
\(O(1)\) (the uniform mode sits at \(-8\) independent of \(N\)), this \(m\)
is an eigenvalue gap, not an extensive energy. Extensive binding would be
\(N\) times a density and is a different observable. Comparing \(m\) to a
rest mass in SI units needs the I1 scale that converts a hopping gap into
a physical energy. That conversion is not fixed by the Rayleigh quotient.
The dimensionless test \(E_0+8\) does not need it.
